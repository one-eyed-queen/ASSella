# 3.0.0

**EXE-fingerprinter is now a terminal-only, .exe-only downloader.** The Qt desktop window and everything around it was removed.

- TUI only: a paws-style terminal interface with sixel graphics where supported and text elsewhere. Colour-blind mode built in; SFW assets only.
- .exe-only downloads: Windows base-game depots via the steamcmd API, `-manifest-only` DepotDownloader dumps, filelist downloads of the selected `.exe`s into `%APPDATA%\exe-pawprint\<appid>`.
- Depot key sources, best to best: the local key database, your private API (HWID-bound accounts with expiry), the public Hubcap.
- Search: AppID, full name, or a few letters — merged from Steam Store, SteamDB, Hubcap and the private API; exact appid first.
- **Private API** (`https://exe-fingerprinter.vercel.app`): username + password with HWID lock on first sign-in and account expiry dates. Admin panel on the Touka Kirishima web side can create external accounts.
- **Removed:** PyQt6 desktop UI, plugins (SpaceBunny/Styx/Lobster), SLSsteam/ACCELA integration, Goldberg/GSE, Steamless, SLScheevo, achievements, workshop/DLC features, update checker, library views, `config.yaml` editing, MRC.
- NI/Linux/macOS data dirs: `~/.local/share/EXE-fingerprinter` / `%APPDATA%\EXE-fingerprinter` / `~/Library/Application Support/EXE-fingerprinter`; downloads go to `exe-pawprint`.
